# PythonPitDungeon
A completely python-coded rpg map creator where users can import tiles and sprites, scale them and move them around, as well as save and load maps. Players can connect to a running game session and move their characters, as well as import their own character icons.

To install, run the .ps1 script with powershell (Right click, run with powershell)
The powershell script will install all required libraries and ask to run the program. Running the install script every time is the easiest way to run the code without error.

The use of AI for this code is limited to the powershell script and finding bugs. AI was NOT used to create actual python code for the app itself. The AI used was Microsoft Copilot.

The KnightIcon and whitePanel pngs are required for running. You may edit them, but do not delete or rename them.

To import a tile or sprite, copy or import the file into the folder the code resides in, then simply type the filename with no path into the import popup when the import button is clicked.
Try to keep to .png files for sprites and tilesets. If you must try, include the filetype in the import popup, or it will not recognize the file.
